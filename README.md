# 🚀 Rocket Booster – A Precision Landing Challenge

**Rocket Booster** is a physics-based 3D space control game built in Unity, where precision, timing, and control are everything.

Take command of a rocket ship and navigate through hazardous environments using thrust and rotation mechanics. Avoid collisions, stabilize your movement, and land safely on the designated platform to complete each level.

---

## 🧩 Features

✅ **Physics-Based Rocket Control**  
Realistic thrust and rotation mechanics for immersive gameplay.

✅ **Precision Landing Gameplay**  
Carefully control your rocket to land safely on platforms.

✅ **Challenging Environments**  
Navigate through obstacles, terrain, and tight spaces.

✅ **Particle Effects System** 🔥  
- Real-time rocket booster flames  
- Visual feedback during thrust

✅ **Sound Effects System** 🔊  
- Thrust sound synced with movement  
- Collision and success feedback sounds  

✅ **Level-Based Progression**  
Each level introduces new challenges and layouts.

✅ **Collision System**  
Crash into obstacles and restart — rewarding careful play.

---

## 🎮 Controls

- **Thrust** → `Spacebar`  
- **Rotate Left** → `Left Arrow`  
- **Rotate Right** → `Right Arrow`  

---

## 🛠️ Developer Debug Controls (Hidden)

- **Disable Collision** → `C`  
- **Next Level Skip** → `N`  

> ⚠️ These are developer/testing shortcuts and not intended for normal gameplay.

## 🚀 How to Run

1. Clone or download the repository  
2. Open in **Unity (2021.3 LTS or newer)**  
3. Open the main scene from the `Scenes` folder  
4. Press **Play**
